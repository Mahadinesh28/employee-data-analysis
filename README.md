# Employee Data Analysis Project

## Project Description
This project analyzes employee data using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Steps
1. Load employee dataset.
2. Clean missing values.
3. Remove duplicate records.
4. Analyze employee data.
5. Create five visualizations.
6. Generate the final report.

## How to Run

Install required libraries:

pip install pandas numpy matplotlib seaborn jupyter

Run the notebook:

jupyter notebook employee_analysis.ipynb

- Summary report
